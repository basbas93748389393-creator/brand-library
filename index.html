云端存储配置（共享图库必需）

图片存储在 Cloudinary，数据库使用 Supabase，实现多人共享同步。

① Cloudinary 配置（存图片）

1. 注册 cloudinary.com↗（免费）

2. 进入 Dashboard，找到 Cloud Name、API Key、API Secret

3. 在 Settings → Upload 中创建一个 Upload Preset（选 Unsigned）

② Supabase 配置（存数据）

1. 注册 supabase.com↗（免费）

2. 新建项目，进入 SQL Editor 执行以下建表语句：

CREATE TABLE assets (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  brand text NOT NULL,
  name text NOT NULL,
  category text,
  image_url text NOT NULL,
  created_at timestamptz DEFAULT now()
);
ALTER TABLE assets ENABLE ROW LEVEL SECURITY;
CREATE POLICY "allow all" ON assets FOR ALL USING (true);

3. 在 Project Settings → API 找到 URL 和 anon key
